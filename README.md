# USA Roofing Website Template

A reusable, production-ready static website for **US** roofing companies (American spelling, USD pricing, gutters, US states), built to the Rank Boss master website specification (technical SEO, local SEO, schema, accessibility, legal drafts). It includes an **instant satellite roof estimate**: the visitor types an address, sees the roof on satellite imagery with the outline detected, picks the pitch and gets a ballpark reshingle price based on the client's own price per square.

Static HTML, CSS and JavaScript. No frameworks and no tracking. Fonts, Leaflet and the hero video are self-hosted. The only third-party requests are the estimate's map services, which run only after a visitor searches an address.

Demo: https://usaroofingdemo.getrankboss.com (also `rankboss-usa-roofing.pages.dev`), noindexed. Cloudflare Pages project `rankboss-usa-roofing` redeploys on every push to `main`. The Canadian version lives in `joshmartire/roofing-website-template`.

## Setting up a new client

1. Edit `_build/site.config.json`: business name, legal name, domain, phone, email, hours, address (or `null` for a service-area business), Google Business Profile, social profiles.
2. Brand and offer:
   - `services`: delete any slug the client doesn't offer. Its pages, links, sitemap entries and form options disappear. Fix any sentences listed in `_build/removed-service-mentions.txt` (QA fails while it exists).
   - `accent`: brand colour `#rrggbb` (the build stops if it's too dark to read).
   - `logo`: client logo in `assets/img/client/` (transparent PNG best).
   - `photos`: the client's own job photos only (see `_build/photos.py`).
3. **Estimate pricing** (`estimator` block), the client's real numbers:
   - `price_per_square`: installed price per roofing square (100 sq ft of roof surface) for a standard asphalt reshingle with one layer torn off.
   - `range_pct` (± around the middle), `waste_pct`, `extra_layer_per_square`, `minimum_job`, `overhang_ft`, `round_to`.
   - `pitches[].price_mult` (steep-roof labour premium) and `storeys[].price_mult`.
   - `map_center` / `search_bias`: the client's area.
   - `enabled: false` removes the tool, its nav links and its legal paragraphs.
   - Optional `google_solar_api_key`: a Google Maps Platform key with the **Solar API** enabled, restricted to the client's domain (HTTP referrer). When set, roof area and pitch come from Google's Solar data where it's available. Google bills per request beyond the free tier.
4. `form_endpoint`: FormSubmit (`https://formsubmit.co/CLIENT-EMAIL`). The first submission sends an activation email that must be confirmed.
5. Cities changed? Rewrite `content_cities.py` and each service's `"cities"` text. Keep it genuinely local.
6. Review everything marked `CLIENT REVIEW` (HTML comments): hero badges, working standards, about page, storm/emergency availability, legal drafts.
7. Build and test:
   ```bash
   pip install pillow fonttools brotli playwright
   python3 _build/build.py
   python3 _build/qa.py
   python3 _build/qa_browser.py --axe path/to/axe.min.js   # axe optional: npm pack axe-core
   ```
8. At launch: set `"domain"` to the client's domain and `"demo_mode": false` (removes noindex and the yellow demo banner).

## Opening animation

The animation plays on **whichever page a visitor opens first** in a browser session, whether that's the home page or a service page from Google. It then never replays during that visit. It's skipped when the URL has a `#hash`, for reduced-motion users, and on the 404 and thank-you pages, and a tap or key press skips it. Headlines are visible from the first paint underneath, so it never hides content from Google. Set `"intro_scope": "home"` to limit it to the home page, or `"intro": false` to turn it off.

## How the instant estimate measures

1. **Address → location:** Photon (OpenStreetMap-based address search), with Nominatim as a fallback.
2. **Outline:** the building footprint from OpenStreetMap, read from OpenFreeMap's vector tiles (fast CDN, no key, commercial use allowed), with the Overpass API as a fallback. Tile precision is about 0.45 m per corner, well inside the ±10% range. The visitor can drag corners, add corners, redraw it, or type a footprint size instead.
3. **Roof area:** footprint + overhang, × the pitch factor √(1 + (rise/12)²), + waste → squares.
4. **Price:** squares × price per square × pitch and storey multipliers (+ extra layers), shown as a range. Never below `minimum_job`.
5. **Lead:** the visitor sends name, phone and email. The address, coordinates, measurements, choices and the range shown are included in the email.

Map imagery: Esri World Imagery. These public services are free for reasonable use but have fair-use limits. For a high-traffic client, consider paid keys (see LAUNCH-CHECKLIST.md). Attribution is shown on the map and must stay.

## Design and motion

- Opening animation: a roof gable draws itself, shingle courses lay down row by row, then the name stamps in and the panels split.
- Hero: drone video (graded, lazy-loaded, paused off-screen, skipped for data-saver and reduced motion) with the instant-estimate card.
- Pinned "anatomy of a roof": deck → ice & water → underlayment → shingles → ridge vent stack into place as you scroll.
- Satellite-trace teaser, storm band with rain and lightning, velocity marquee, scroll-fill statement, card spotlights.
- Everything respects `prefers-reduced-motion` and works without JavaScript (the estimate shows a call/contact fallback).

## Deploying

Cloudflare Pages (like the other Rank Boss demos): connect the repo, no build command, output directory `/`. `_headers` noindexes the `*.pages.dev` hostname only. For GitHub Pages: Settings → Pages → `main` / root; the build writes `CNAME` once a real domain is set.
